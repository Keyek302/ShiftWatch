# Shift Watch

Shift timer and earnings tracker. Works offline and installs to your home screen.

## Put it online (GitHub Pages)
1. Create a repo (for example `ShiftWatch`) and upload every file in this folder to the root.
2. Settings → Pages → Deploy from a branch → `main` / root → Save.
3. Open `https://<your-username>.github.io/ShiftWatch/` in Chrome.
4. Chrome menu → Install app (or Add to Home screen).

## Notes
- Shifts are saved in the browser on that address. Moving to a new address starts empty.
- Icon badge shows whole dollars left. Live notification shows dollars left, time left and the finish time.
- Floating countdown uses Picture-in-Picture (Chrome, Edge, Safari, Samsung Internet).
